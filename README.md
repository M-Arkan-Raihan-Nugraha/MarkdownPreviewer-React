# Markdown Previewer

Aplikasi React sederhana untuk menulis Markdown dan melihat hasil preview HTML secara langsung.

## Fitur

- Editor Markdown real-time
- Preview HTML otomatis
- Sanitasi HTML dengan DOMPurify
- Layout responsif untuk desktop dan mobile
- Counter jumlah karakter

## Teknologi

- React
- Vite
- marked
- DOMPurify

## Cara Menjalankan

```bash
npm install
npm run dev
```

## Build Production

```bash
npm run build
```
